## 🌟 核心特色與教學亮點

1. **開局規則指引與詳細秘笈（雙處整合）**：
   - 開局選單上方內建「**📖 遊戲規則與過關指南（開局必讀）**」，包含實體翻書、裁判監督、插旗佔地與四輪結算 4 大重點。
   - 頂部導航列與開局卡片皆設有「**📖 規則說明**」按鈕，隨時可展開彈跳視窗查閱 5 大詳細規則細則與過關秘笈。
2. **實體翻書挑戰（每輪隨機換頁與換題）**：
   - 螢幕大字體指引：「**請翻開數學課本 第 XX 頁 第 X 題**」。
   - **每輪隨機換頁換題機制**：
     - 單元 1（一億以內的數）：隨機切換 **第 18 頁、第 19 頁**（連續進位、大數讀寫、大小比較、位值拆解、營業額應用）。
     - 單元 2（乘法）：隨機切換 **第 30 頁、第 31 頁**（牛奶干擾題、3007×59含零乘法、體育館椅子、1125×8、自強號車票）。

   - 作答者翻課本在**實體小白板**動筆計算，裁判監督翻到指定頁數審查答案，增進同儕合作、互審與鷹架支持。
2. **小白板計算、裁判翻書審查與四向獎懲佔地博弈（新核心規則）**：
   - **作答者小白板解題**：作答者使用實體小白板列出直式計算或幾何度數，點選送出選項後暫不揭示對錯，交由裁判審查。
   - **裁判翻書審查核對**：裁判必須翻開實體課本指定頁數題號核對作答者答案，點選「審查判定：正確」或「抓出錯誤：不正確」。
   - **四大裁決情境與佔地權限**：
     1. **作答正確 且 裁判審查正確**：雙方依比例賺取金幣（作答者 $120、裁判 $60），作答者享有花金幣插旗佔領該地之優先權。
     2. **作答不正確 且 裁判審查出錯誤**：裁判成功抓錯獨得 $150 獎勵金，**換由裁判獲得插旗佔領該地之權限**！
     3. **作答不正確 且 裁判沒審查出錯誤（雙人連帶處罰・互審機制）**：
        - **不直接給出答案**：拒絕照抄！系統不提供答案與步驟，僅提供課本指定出處頁數，強制兩位同學親自翻課本查概念、在小白板上算題。
        - **雙方互相擔任裁判**：兩人各自抽到不同之課本原題，並互相翻書擔任對手的裁判審查小白板算式，**兩人同時審查對方都通過（✅ 通過）才能順利解除處罰**（免除任何金額罰款）。
        - **最多三輪處罰循環**：若有一人未通過，系統立即抽換全新課本題目進入第 2 輪（至多 3 輪）；若三輪皆未全員通過，**依規則僅對「累計未通過最多次」的玩家實施金額處罰（扣除金幣 -$100）**；若兩人未通過次數相同則雙方一同扣款，第三輪結束後強制結案回歸對局。
     4. **作答正確 但 裁判誤判為不正確**：裁判誤判冤枉對手無審查獎勵，作答者平反獲得 $120 獎金並可選擇是否佔地。
3. **事件、補給站與加速格專屬任務（拒絕白吃白喝，全格具備教育任務）**：

## 🚀 使用方式

1. 點擊開啟本目錄下的 [`index.html`](file:///Users/tunyuan/Library/CloudStorage/GoogleDrive-asc103138@st.tc.edu.tw/我的雲端硬碟/115四上期中數學複習遊戲/index.html)。
2. 兩位小朋友各自在下拉選單中挑選自己的**座號（1~28 號）**。
3. 點擊「**🚀 認證座號・開始大富翁！**」進入遊戲。
4. 依序輪流點擊中央 3D 骰子，依步數前進。踩中題目格時，系統會**隨機指派該單元不同的課本頁數與大題**，學生需依指示翻開實體課本解題。
5. 時間倒數歸零時自動響笛結算，頒發大富翁總冠軍，若平手則啟動「黃金搶答驟死賽」！
